<p align="center"><em>"Quality over quantity. Here are the core backend systems I've built to solve practical workflows."</em></p>

### ⚡ EV Charging Station Management System
*Một hệ thống Backend mạnh mẽ được thiết kế để giám sát, điều khiển và quản lý hiệu quả các trạm sạc xe điện.*
- 🚀 **Kiến trúc:** Phát triển theo mô hình Microservices (User, Station, Booking, Payment) giúp hệ thống mở rộng linh hoạt.
- 🔐 **Tính năng:** Tích hợp xác thực bảo mật chuẩn JWT, tối ưu hóa luồng dữ liệu qua Ocelot API Gateway và cập nhật trạng thái thời gian thực bằng SignalR.
- 🛠 **Công nghệ:** C# (.NET Core), Web API, Ocelot, MySQL, SignalR, Docker.

### 📊 StratHub – Nền tảng SaaS Quản lý Không gian làm việc
*Hệ thống hỗ trợ quản lý công việc và chiến lược đội ngũ toàn diện.*
- 🔄 **Tính năng:** Tích hợp bảng quản lý Kanban tương tác thời gian thực thông qua Socket.io và cơ chế tự động làm mới mã bảo mật token (auto-refresh token).
- 🛠 **Công nghệ:** Node.js, Express, JavaScript, Socket.io, REST API, JWT.
